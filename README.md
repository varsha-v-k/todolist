# To-Do List CLI App

A simple command-line to-do list application for the CodeOrbit Tech Python Programming Internship.

## Features
- Add tasks
- View tasks in a numbered list
- Remove tasks by number
- Separate functions for each feature
- Handles invalid menu choices and task numbers

## Requirements
Python 3

## Run
Open the folder in VS Code, choose **Terminal → New Terminal**, then run:

```bash
python todo_list.py
```

On Windows, you can try `py todo_list.py` if needed.

## Test
1. Choose 1 and add `Complete Python internship task`.
2. Choose 1 and add `Upload project to GitHub`.
3. Choose 2 and confirm both tasks appear numbered.
4. Choose 3 and enter 1 to remove the first task.
5. Choose 2 and confirm the task is gone.
6. Try an invalid menu option or an invalid task number.

## Note
Tasks are stored in a Python list only while the program runs. They are not saved after exit; file saving is optional in the instructions.
